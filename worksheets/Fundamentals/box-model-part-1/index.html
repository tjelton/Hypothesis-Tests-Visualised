The Box Model Part 1 - What is the Box Model?

Keep the Interface Page Open in Another Tab /Fundamentals/box-model-part-1/

This page introduces the box model. It is a read-and-play page rather than a problem-solving one, so this worksheet is deliberately short.

What to do

There are no recommended tasks for this lesson beyond the interactive page itself. Simply work down the page from top to bottom, reading all of the material, and complete each Your turn! section — the prompts written in blue — as you reach it.

There are three of them, one in each of these cards:

  • Simulating Box-Model Draws
  • Representing the Problem Numerically
  • Testing Your Own Box

None of them have a single right answer — they are there to let you play with the box model until the idea of drawing tickets from a box feels natural.
