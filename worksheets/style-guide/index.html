Authoring reference

Worksheet building blocks

Every component available when writing a worksheet, rendered next to the markup that produces it. Copy from here rather than inventing new classes, so the pages stay consistent. This page is for whoever is writing the worksheets — students have no reason to visit it.

Recommended Task 1

A recommended task — the core path

The default task type. Teal accent. Use for the tasks every student should do, in the order they should do them. 

<section class="task task--recommended" id="task-1">
  <div class="task-head">
    <span class="task-badge">Recommended Task 1</span>
    <h2 class="task-title">Getting Familiar</h2>
  </div>
  <div class="task-body">
    …
  </div>
</section>
Note The id is the task's link anchor, so keep it stable once a page is published — anyone who linked to …/box-model-part-3/#task-2 would otherwise land at the top of the page instead.
Coding Task 1

A coding task — do it again in R

Violet accent. Class task--coding.

library(tidyverse)

# 100 coin flips, repeated 10,000 times, keeping the sum each time.
sums <- replicate(10000, sum(sample(c(0, 1), size = 100, replace = TRUE)))
mean(sums)

Component

Screenshots

Screenshots live in an img/ folder next to the worksheet's index.html. Until one is taken, drop in a placeholder that says exactly what to capture: 

<!-- placeholder -->
<figure class="shot shot--todo">
  <div class="shot-frame"><span><b>Screenshot needed:</b> …</span></div>
  <figcaption>Figure 1 — …</figcaption>
</figure>

<!-- the real thing -->
<figure class="shot">
  <img src="img/box-parameters.webp" alt="The Box Parameters section …">
  <figcaption>Figure 1 — …</figcaption>
</figure>
Before committing Compress screenshots first. A raw retina PNG is 2–5 MB; the same image as WebP is around 150 KB, and git history keeps every version of it forever.
