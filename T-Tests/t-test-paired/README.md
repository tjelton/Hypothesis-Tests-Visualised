# Paired t-Test — pure JavaScript port

A dependency-light static-page rewrite of the Shiny "Paired t-Test" lesson
(`R/ttest_paired_*.R` and `R/utility_load_data_paired_sample_*.R`). No
webR/shinylive: the page is plain HTML + hand-written JS, so it loads like any
normal web page.

A paired t-test **is** a 1-sample t-test applied to the paired difference
(condition 2 − condition 1). The Shiny app reflects this by reusing its generic
`ttest_1_sample_generic_*` modules here, so this port reuses the 1-sample
lesson's calculation/plot/box-model code almost verbatim. The only display
differences are the `\mu_d` subscript in the hypotheses and expected value, and
a default null value of 0.

## Running locally

Any static file server works, e.g. from the repo root:

```sh
python3 -m http.server 8000
# then open http://localhost:8000/T-Tests/t-test-paired/
```

## Layout

This lesson holds only its own content; the numeric engine, plots, box-model
helper and CSS live in the sibling **`../../shared/`** directory (see
`../../shared/README.md`) and are used by every port.

| File | Purpose |
|---|---|
| `index.html` | All static teaching content (ported verbatim from the R UI files) |
| `js/datasets.js` | Generated — the 5 paired datasets copied verbatim from R (`tools/generate_datasets.R`) |
| `js/app.js` | Reactive wiring: the two-condition data loader plus the 1-sample chain applied to the paired difference |
| `../../shared/js/stats.js` | R-equivalent numerics (verified against R to ~1e-15) |
| `../../shared/js/plots.js` | SVG re-implementations of the base-R plots |
| `../../shared/js/boxmodel.js` | Port of `box_model_html()` |
| `../../shared/css/style.css` | Shared theme |

External assets (CDN): Bootstrap 5 (Bootswatch Lumen) and MathJax 3.

## Datasets

Copied verbatim from `R/utility_load_data_paired_sample_srv.R`:

* **SleepStudy** — base R's `sleep`, reshaped wide (real data).
* **BloodPressureStudy, CognitiveScores, FitnessTestResults, DietImpactStudy** —
  synthetic, generated by a single `set.seed(1)` followed by the data frames in
  source order. `tools/generate_datasets.R` reproduces the exact RNG stream, so
  every value matches R.

## Fidelity to the Shiny version

* The default view (BloodPressureStudy, condition 1 = Before_Treatment,
  condition 2 = After_DrugA) reproduces the numbers quoted in the intro modal:
  s = 17.346, OV = −4.373, TS = −1.381 — confirmed against R.
* All displayed numbers follow the same round-then-parse chain as the R modules
  (see the header comment in `js/app.js`).
* Teaching text is verbatim, including existing quirks carried over from the R
  source: the duplicated `\mu_1` in the intro modal (the second should be
  `\mu_2`), the intro box model showing `s = 4.751` while the text says 17.346,
  the "1-sample z-test" wording in the CI section, and the "α =" label on the
  confidence-level input. Fix them here and in the R sources together, so the
  two versions stay in sync.

### Deliberate deviations (R-side quirks not reproduced)

* Manually entered values that fail to parse are dropped per condition before
  the equal-length check (matching the 1-sample port's handling of `NA`).

## Tests

```sh
# End-to-end calc chain (against R ground truth) + SVG generation + app.js load.
# Runs on stock macOS, no Node needed:
osascript -l JavaScript T-Tests/t-test-paired/tests/smoke_jxa.js
```

`tests/expected_pipeline.json` is the R-computed result of the full lesson
calculation chain for the default BloodPressureStudy selection
(`tools/generate_expected_pipeline.R`).

The numeric engine (`../../shared/js/stats.js`) is shared and its
distribution/quantile accuracy is verified against R by the shared suite
(`../../shared/tests/`), so it is not re-tested here.

## Deploying

Per the migration plan in `CLAUDE.md`: never place this folder inside
`inst/app` or `site` (the shinylive export rebuilds those wholesale). Copy the
`T-Tests/t-test-paired/` directory to the **`gh-pages` branch as a top-level dir**,
alongside the shinylive export, served at
`https://tjelton.github.io/Hypothesis-Tests-Visualised/T-Tests/t-test-paired/`.
