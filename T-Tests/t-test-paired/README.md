# Paired t-Test

A paired t-test **is** a 1-sample t-test applied to the paired difference
(condition 2 − condition 1), so this lesson reuses the 1-sample lesson's
calculation, plot and box-model code almost unchanged. The only display
differences are the `\mu_d` subscript in the hypotheses and expected value, and
a default null value of 0.

## Running locally

Any static file server works, e.g. from the repo root:

```sh
python3 -m http.server 8000
# then open http://localhost:8000/T-Tests/t-test-paired/
```

## Layout

This lesson holds only its own content; the numeric engine, plots, box-model
helper and CSS live in the sibling **`../../shared/`** directory (see
`../../shared/README.md`) and are used by every lesson.

| File | Purpose |
|---|---|
| `index.html` | All static teaching content |
| `js/datasets.js` | Generated — the 5 paired datasets (`tools/generate_datasets.R`) |
| `js/app.js` | Interactive wiring: the two-condition data loader plus the 1-sample chain applied to the paired difference |
| `../../shared/js/stats.js` | Numerics matching R (verified to ~1e-15) |
| `../../shared/js/plots.js` | SVG implementations of the plots |
| `../../shared/js/boxmodel.js` | The box-model diagram helper |
| `../../shared/css/style.css` | Shared theme |

External assets (CDN): Bootstrap 5 (Bootswatch Lumen) and MathJax 3.

## Datasets

* **SleepStudy** — base R's `sleep`, reshaped wide (real data).
* **BloodPressureStudy, CognitiveScores, FitnessTestResults, DietImpactStudy** —
  synthetic, generated by a single `set.seed(1)` followed by the data frames in
  source order. `tools/generate_datasets.R` reproduces the exact RNG stream.

## Behaviour notes

* Displayed numbers follow a round-then-parse chain (see the header comment in
  `js/app.js`).
* Manually entered values that fail to parse are dropped per condition, before
  the equal-length check.

## Reference values

Default view (BloodPressureStudy, condition 1 = Before_Treatment, condition 2 =
After_DrugA): s = 17.346, OV = −4.373, TS = −1.381 — confirmed against R, and the
numbers the intro modal quotes.

## Known issues

* **The intro modal's box model shows `s = 4.751`** — the 1-sample lesson's value
  — while the modal text alongside it says 17.346.
* **The intro modal uses `\mu_1` twice**; the second should be `\mu_2`.
* The CI section says "in a 1-sample **z-test**".
* The confidence-level input is labelled "α =" while holding 0.95.
* The conclusion says "accept the null hypothesis" rather than "fail to reject".
* The p-value section's last paragraph says the test statistic falls on a
  "standard normal curve" rather than a t-curve.

## Tests

```sh
# End-to-end calc chain (against R ground truth) + SVG generation + app.js load.
# Runs on stock macOS, no Node needed:
osascript -l JavaScript T-Tests/t-test-paired/tests/smoke_jxa.js
```

`tests/expected_pipeline.json` is the R-computed result of the full lesson
calculation chain for the default BloodPressureStudy selection
(`tools/generate_expected_pipeline.R`).

The numeric engine (`../../shared/js/stats.js`) is shared and its
distribution/quantile accuracy is verified against R by the shared suite
(`../../shared/tests/`), so it is not re-tested here.

## Deploying

The live site is served from the `gh-pages` branch, which mirrors `main` exactly
— every lesson keeps the same path it has here. `tools/deploy_gh_pages.sh`
publishes `origin/main` verbatim (plus a `.nojekyll` marker), so there is nothing
to copy per lesson and no separate step for `../../shared/` or the root
`index.html`:

```sh
bash tools/deploy_gh_pages.sh
```
