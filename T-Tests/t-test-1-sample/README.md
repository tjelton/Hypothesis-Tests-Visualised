# 1-Sample t-Test — pure JavaScript port

A dependency-light static-page rewrite of the Shiny "1-Sample T-Test" lesson
(`R/ttest_1_sample_*.R` and its sub-modules). No webR/shinylive: the page is
plain HTML + hand-written JS, so it loads like any normal web page.

## Running locally

Any static file server works, e.g. from the repo root:

```sh
python3 -m http.server 8000
# then open http://localhost:8000/T-Tests/t-test-1-sample/
```

(Opening `index.html` via `file://` also works, but the CDN assets — Bootstrap
Lumen and MathJax — need network access either way.)

## Layout

This lesson holds only its own content; the numeric engine, plots, box-model
helper and CSS live in the sibling **`../../shared/`** directory (see
`../../shared/README.md`) and are used by every port.

| File | Purpose |
|---|---|
| `index.html` | All static teaching content (ported verbatim from the R UI files) |
| `js/datasets.js` | Generated — datasets copied verbatim from R (`tools/generate_datasets.R`) |
| `js/app.js` | Reactive wiring, replicating the Shiny modules' calculation chain |
| `../../shared/js/stats.js` | R-equivalent numerics: `pt`/`qt`/`dt`/`qnorm`, `sd`, quantile type 7, `fivenum`, `ppoints`, R-style `round()`/`as.character()` |
| `../../shared/js/plots.js` | SVG re-implementations of the base-R plots (histogram, boxplot, QQ plot, shaded t-curve) |
| `../../shared/js/boxmodel.js` | Port of `box_model_html()` |
| `../../shared/css/style.css` | `tight_card()` look, body zoom, wide modal — mirrors the Shiny theme |

External assets (CDN): Bootstrap 5 (Bootswatch Lumen, same theme as the Shiny
app) and MathJax 3. Everything else is self-contained.

## Fidelity to the Shiny version

* **Mr. Han's Math Class** uses the exact same seeded sample as the Shiny app
  (`set.seed(1); rnorm(25, mean = 142, sd = 5)`), baked into `datasets.js`.
* All displayed numbers follow the same round-then-parse chain as the R
  modules (e.g. the test statistic is computed from the *rounded* EV/SE
  strings, exactly as `ttest_1_sample_generic_test_statistic_srv.R` does).
* `pt`/`qt`/`dt`/`qnorm` are verified against R to ~1e-10 relative accuracy or
  better (including far tails) by the shared suite in `../../shared/tests/` — far
  beyond the 4–5 decimal places displayed.
* Teaching text is verbatim, including existing typos ("proivde", "deata",
  "becuase", the modal title "1-sample s-test", the duplicated CLT bullet,
  and the "α =" label on the confidence-level input). Fix them here and in the
  R sources together, so the two versions stay in sync.

### Deliberate deviations (R-side quirks not reproduced)

* Manually entered values that fail to parse are **dropped** (with the same
  red warning). The R app stores them as `NA`, which makes `sd()` return `NA`
  and breaks every downstream section.
* The optional categorical filter is re-applied consistently when the numeric
  column changes or the filter is set back to "(None)". In the R app those
  flows could leave stale (still-filtered or unfiltered) data behind.
* The CI conclusion compares the null value to the interval **numerically**;
  the R module compares a character string against a number (lexicographic
  comparison after coercion), which can misorder values with different digit
  counts.

## Tests

```sh
# Stats accuracy lives with the shared engine (run once for all lessons):
node shared/tests/stats.test.mjs
osascript -l JavaScript shared/tests/run_jxa.js

# This lesson's end-to-end calc chain + SVG generation (stock macOS, no Node):
osascript -l JavaScript T-Tests/t-test-1-sample/tests/smoke_jxa.js
```

`tests/expected_pipeline.json` is the R-computed result of the full lesson
calculation chain for Mr. Han's data (`tools/generate_expected_pipeline.R`).
The shared stats ground truth (`../../shared/tests/reference_values.json`) is
generated by `../../shared/tools/generate_reference_values.R`.

## Deploying

Per the migration plan in `CLAUDE.md`: never place this folder inside
`inst/app` or `site` (the shinylive export rebuilds those wholesale). Copy the
`T-Tests/t-test-1-sample/` directory to the **`gh-pages` branch as a top-level dir**,
alongside the shinylive export, e.g. served at
`https://tjelton.github.io/Hypothesis-Tests-Visualised/T-Tests/t-test-1-sample/`.
