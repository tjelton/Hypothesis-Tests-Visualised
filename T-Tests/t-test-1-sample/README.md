# 1-Sample t-Test

The 1-sample t-test compares a sample mean against a hypothesised population
mean when the population standard deviation is **unknown**, so the sample SD
stands in for it and the p-value comes from the t-distribution:

```
SE-hat = s / √n;   t = (OV − EV) / SE-hat;   df = n − 1;   p-value from pt
```

## Running locally

Any static file server works, e.g. from the repo root:

```sh
python3 -m http.server 8000
# then open http://localhost:8000/T-Tests/t-test-1-sample/
```

(Opening `index.html` via `file://` also works, but the CDN assets — Bootstrap
Lumen and MathJax — need network access either way.)

## Design notes

Things a future edit could easily undo by accident:

* **The box is labelled `σ ≈ s`, never `σ = s`.** σ is the box's real spread and
  is unknown; s is the sample standing in for it. Writing `=` there asserts the
  exact misconception the lesson exists to correct, so `tests/smoke_jxa.js`
  fails if the `≈` disappears.
* **The confidence level is derived as 1 − α** rather than taken as a second
  input, and the interval's sidedness follows the alternate hypothesis. Those
  choices are what make the CI and p-value sections always agree, so there is
  deliberately no confidence-level box to fill in. The smoke test asserts the
  agreement for all three alternatives.
* Displayed numbers follow a **round-then-parse chain**: the test statistic is
  computed from the already-rounded EV and SE strings, not from full precision.
  Change this and every displayed value shifts in the last decimal place.
* Manually entered values that fail to parse are **dropped**, with a red warning
  naming how many were unusable.
* The optional categorical filter is re-applied when the numeric column changes
  or the filter is set back to "(None)".
* The CI conclusion compares the null value to the interval numerically.

## Reference values

Mr. Han's data, null 140, two-sided, α = 0.05 — confirmed against R:

| quantity | value |
|---|---|
| s | 4.75054 |
| SE-hat | 0.95011 |
| TS | 2.9926 |
| df | 24 |
| p (two-sided) | 0.00632 |
| 95% CI | (140.8824, 144.8043) |

For comparison, the z-test on the same data with σ taken as the sample SD gives
p = 0.00277 — less than half, which is the cost of pretending an estimated SD is
a known one.

## Tests

```sh
# Stats accuracy lives with the shared engine (run once for all lessons):
node shared/tests/stats.test.mjs
osascript -l JavaScript shared/tests/run_jxa.js

# This lesson's end-to-end calc chain + SVG generation (stock macOS, no Node):
osascript -l JavaScript T-Tests/t-test-1-sample/tests/smoke_jxa.js
```

`tests/expected_pipeline.json` is the R-computed result of the full lesson
calculation chain for Mr. Han's data (`tools/generate_expected_pipeline.R`).
